# Code de conduite

Les échanges doivent rester accueillants, respectueux, factuels et centrés sur le projet. Le
harcèlement, les attaques personnelles, la publication de renseignements privés et tout contenu
discriminatoire sont interdits.

Signalez un comportement problématique en privé au mainteneur via les fonctions de signalement de
GitHub. Le mainteneur peut modérer, masquer ou bloquer les interactions qui ne respectent pas ces
règles. Cette politique s'applique aux issues, discussions, pull requests et espaces officiels du
projet.
